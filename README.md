# محطة الزيوت الذكية — تحديثات ويندوز

هذا المستودع يحوي **ملفات تثبيت وتحديث تطبيق ويندوز فقط** — لا كود مصدري هنا.

تطبيق ويندوز يفحص آخر إصدار منشور هنا تلقائياً، ولا يثبّت أي تحديث إلا إذا طابق توقيعاً رقمياً لا يملك مفتاحه إلا صاحب المشروع.

لتثبيت التطبيق لأول مرة: نزّل ملف `OilStationSetup-*.exe` من [صفحة الإصدارات](https://github.com/facebooksan35-sketch/oil-station-releases/releases/latest) وشغّله.

Installers and signed update manifests for the Oil Station Windows app. No source code here. Every update is verified against an Ed25519 signature before it is installed.
